Playground

Write a Kwilos.js app and run it here. The page runs Kwilos.js {{version}}, which your code imports as kwilos.js, and kwilos.js/aseprite is there too. It draws on a canvas with the id canvas, 600 by 360. Nothing is sent anywhere: your code and files stay in your browser, and a link to your code carries the code itself.

Ctrl or ⌘ and Enter runs the code. Press Escape, then Tab, to leave the editor.

Click the app to give it the keyboard.
